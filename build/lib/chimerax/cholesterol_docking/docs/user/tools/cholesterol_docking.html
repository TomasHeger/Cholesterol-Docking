Cholesterol Docking V7

Open a cryo-EM map and fitted protein model, choose them in the tool, set the contour used to recognize cholesterol/lipid-like rods, and click Find & Dock Cholesterols.

Standard search (1500 orientations) is the recommended starting point. Fast is useful for testing; Thorough is intended for final searches.

The tool writes accepted structures, confidence-tier structures, membrane-model information, neighbor groups, final selections, and detailed site diagnostics to the chosen output folder.

Always inspect candidate assignments in the experimental map. Automated placement is candidate generation and scoring, not proof of cholesterol identity or occupancy.
